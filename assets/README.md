# 中国汽车市场分析 · 展示资产

这里存放会随项目一起展示或提交到 GitHub 的最终图片与演示素材；它不是模型运行时的中间输出目录。

## 目录

- `analysis/`：经筛选的新版实验图；
- `dashboard/zh/`：新版中文看板截图；
- `dashboard/en/`：新版英文看板截图；
- `demo/`：新版看板演示录屏。

当前目录已经补齐新版分析图、中英文看板截图和中文功能演示。README 只引用这里的最终展示文件，不再引用旧版 `figures/` 截图。

## 选择原则

仅保留能够直接支持项目核心结论的图：时间切分下的销量预测、用户口碑特征消融与稳健性、配置年销量归因、用户需求与风险预警，以及冷启动折中方案。探索性图、旧版 150 系结果、过期看板截图和重复图片不作为最终展示素材。
